# Ховор ургамлын сан

Glass загвартай, Монголын Улаан ном (2013)-ын «Дээд ургамал» хэсгийн
№1–135 ургамлыг агуулсан статик веб.

## Ажиллуулах

Энэ хавтас дотроос:

```sh
python3 -m http.server 4173
```

http://localhost:4173 хаягийг нээнэ. Build болон npm install шаардлагагүй.

## Мэдээлэл

- `data/plants.js`: вебийн ашигладаг 135 ургамлын өгөгдөл.
- `data/plants.json`: ижил өгөгдлийн JSON хувилбар.
- `assets/plants/`: PDF-ээс гаргасан 135 эх зураг (ургамлын зураг, тархацын газрын зураг).
- `sources/mongolian-red-book.pdf`: хэрэглэгчийн өгсөн эх PDF.
- `script.js`: хайлт, шүүлтүүр, дэлгэрэнгүй цонхны үйлдлүүд.
- `index.html`, `styles.css`: бүтэц, загвар.

Хуучин 100 ургамлын өгөгдлийг бүрэн сольсон. Шинэ мэдээллийг хэрэглэгчийн өгсөн
PDF-ийн 222–397-р хуудаснаас гаргасан. Бүх ургамлын эх бичвэр `fullText` талбарт
хадгалагдсан. `sections` талбарт уншихад тохиромжтойгоор бүлэглэсэн.
Эх номын үг үсгийн алдаа болон давхардсан өгүүлбэрүүдийг эх бичвэрт хадгалсан.
Ургамлын дэлгэрэнгүйгээс эх PDF-ийн хуудсыг нээж болно.

IUCN ангиллууд нь номд дурдсан үеийн үнэлгээ; одоогийн үнэлгээ гэж үзэхгүй.
Бүс нутаг, амьдрах орчны шүүлтүүрийг тархацын бичвэрийн түлхүүр үгээр
гаргасан тул бүрэн мэдээллийг дэлгэрэнгүй болон эх PDF-ээс шалгана.
Өнгө, цэцэглэх сарын хуучин шүүлтүүрийг баталгаагүй утгаар дүүргэлгүй хассан.

## PDF-ээс дахин импортлох

Python орчиндоо `pymupdf` суулгаад:

```sh
python3 tools/import_redbook.py '/path/to/MONGOLYN ULAAN NOM - BAIGAL ORChIN NOGOON KhOGZhLII.pdf'
```

Импортлогч нь энэ 466 хуудастай PDF-ийн бүтэц, дугаарлалтад зориулсан.
Өгөгдлийн хоёр файл, зургууд болон локал эх PDF-ийг шинэчилнэ.
Гараар өгөгдөл засахдаа вебийн ашигладаг `data/plants.js`-ийг өөрчилнө;
дахин импорт хийхэд тэр өөрчлөлтүүд дарагдана.
